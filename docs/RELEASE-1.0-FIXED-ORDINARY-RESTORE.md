## Limits and next gate

This is synthetic same-host ordinary partial restore with external transport
instrumentation. It does not qualify real provider authentication or renewal
after restore, encrypted/cloud/full-system/fresh-machine variants, an arrival
gap, deliberately pending shutdown writes, HACS delivery or stable release.
A complete snapshot can restore both ledger and witness; local continuity is
not an external monotonic counter. A pre-fix archive can also restore vulnerable
code, so the fixed candidate must be installed before recovery.

The earlier full-package run binds 012a/98a. The next engineering gate is the
complete native package suite on this exact fixed package, followed by the
remaining explicit release-plan gates. The branch stays draft; no stable tag,
release, merge or production upgrade is authorized by this result.
