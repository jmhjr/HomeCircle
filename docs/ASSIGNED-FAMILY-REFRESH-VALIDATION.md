# Assigned-tracker family refresh candidate

This is an unpublished development candidate after beta 17. It retains the beta 17 version number for the local test build and does not replace the immutable HACS tag or published ZIP. The published beta 17 review does not cover this new change.

The family button plans only explicitly assigned trackers, independently of the current map source and usable-position/freshness checks. Supported Home Assistant phones require the existing member request opt-in and a registered same-device notification target. External Life360 can batch a complete selected Circle using the existing opt-in and credential boundary; an incomplete selected Circle uses only the installed supported entity-targeted action. HomeCircle-managed connections group cloud report checks. Unknown providers are skipped, without guessing an update action. Disabled/unavailable sources and per-source limits/failures do not prevent other eligible requests.

Household read permission is required before planning; all planned tracker/notification control permissions are checked before reservation and again before dispatch. Registry identity, selection, opt-in and client ownership are rechecked after awaited persistence and previous provider operations. Concurrent clicks share an atomic persisted reservation. Existing Circle budgets remain separate; phones and targeted actions share the source budgets used by individual/automatic requests, and mixed-family clicks have their own persisted button budget. Each budget remains 50 attempts per rolling 24 hours with a one-minute deliberate cooldown. Provider backoff is retained, failures consume reservations, and failed persistence prevents dispatch.

Feedback observes for two minutes and expires five minutes after completion. Tracker-supplied report advance is distinct from an HA last-reported/updated receipt; the latter is labeled GPS-unconfirmed. Assigned sources can be observed even when Person or another tracker supplies the map. Multi-source member feedback lists provider outcomes. Source changes and late evidence do not rewrite frozen results. No raw credentials, cloud IDs or remote reply bodies enter feedback.
