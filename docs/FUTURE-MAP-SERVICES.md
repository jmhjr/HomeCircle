# Future routes, traffic, and radar providers — research snapshot, 2026-10-04

This is a shortlist for later HomeCircle releases, not a provider selection or an integration promise. Free allowances, coverage, licenses, and API behavior can change; recheck them before implementation. External route and address requests can disclose precise household locations, so each feature needs an explicit opt-in, a clear network disclosure, bounded caching, visible attribution, and a useful fallback when the service fails. Keep API keys out of public card code where the provider supports server-side requests.

| Need | Candidate | Current free scope and tradeoff |
| --- | --- | --- |
| Traffic-aware route and travel time | [TomTom Routing API](https://docs.tomtom.com/pricing) | Its published pricing lists 20,000 free routing requests per month and says routes can include traffic. This is a free allowance on a metered commercial service, not an unlimited free service. A provider key and quota handling are required. |
| Traffic overlay | [TomTom traffic flow and incident tiles](https://docs.tomtom.com/pricing) | Its published pricing lists 200,000 free raster or vector traffic tile requests per month. Tile counts can grow quickly on an always-visible map, so measure realistic wall-display usage before choosing it. |
| Route without live traffic | [openrouteservice](https://openrouteservice.org/plans/) | The Standard plan is free with published request limits. It does not include live traffic; use it for route geometry and non-traffic travel estimates, never label its result a live-traffic ETA. [Provider traffic clarification](https://ask.openrouteservice.org/t/isochrone-trafic-data/7875). |
| Global precipitation radar | [RainViewer Weather Maps API](https://www.rainviewer.com/api.html) | Free without a key for personal, educational, and small community use, with attribution and best-effort availability. Its [2026 transition notice](https://www.rainviewer.com/api/transition-faq.html) limits the public API to past radar frames, drops nowcast, caps zoom at 7, and states a 100 requests/IP/minute limit. The [live metadata endpoint](https://api.rainviewer.com/public/weather-maps.json) currently has an empty `nowcast` list. License fit for a distributed integration needs review. |
| U.S. precipitation radar | [National Weather Service radar OGC services](https://www.weather.gov/documentation/services-web-api) | U.S. government weather data is free to use, with reasonable rate limits. The ordinary NWS JSON API does not provide radar display imagery; the NWS points developers to separate radar OGC services. This is a U.S.-only alternative with more map-layer integration work. |

First prototype choice: evaluate TomTom for traffic-aware routes and overlay, and RainViewer for a simple optional radar layer. Keep openrouteservice as a route-only fallback and assess NWS OGC radar for U.S. deployments. Before adding any service, verify its current terms, quotas, attribution, geographic coverage, request costs under kiosk use, and behavior when the API or key fails. Do not enable paid usage silently.
