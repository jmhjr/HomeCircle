# Beta 19 candidate validation

Status: development candidate on `codex/findmy-beta`; installed for owner-authorized HA OS testing, not published. The private prototype remains in place; no account migration has occurred.

## Scope and provenance

Apple Find My is included as a native provider in HomeCircle. The SDK is MIT-licensed FindMy.py, pinned to `7969003ca785658369b650f75d9e7ca519566bf6`, with its copyright/license retained. Python imports use a private namespace. Identity-library initialization/cache writes run off the event loop, serialized and atomic. Runtime dependencies are declared separately; Apple identity libraries and other dependency binaries are not included in the HACS archive. No HAtag/export-findmy Rust source or binary is redistributed.

See [promotion and scope](FIND-MY-BETA-PROMOTION.md) for consent, selected-item storage, account isolation, migration and recovery details.
