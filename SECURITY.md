# Security reporting

Report a suspected HomeCircle vulnerability through GitHub's
[private vulnerability reporting](https://github.com/jmhjr/HomeCircle/security/advisories/new).
Do not include exploit details or account data in a public issue.

Provide the HomeCircle and Home Assistant versions, installation method and a
minimal synthetic reproduction. Do not send passwords, tokens, verification
codes, device passcodes, vaults, keys, backups, raw provider responses, household
locations or private image URLs. A private report does not require those secrets.
Never consume a device-passcode attempt to reproduce a bug.

HomeCircle has no hosted diagnostic-upload service and does not automatically
send diagnostics or telemetry to the maintainer. Read the
[detailed reporting policy](docs/SECURITY.md) and [support guide](SUPPORT.md).
No response time, provider availability or emergency monitoring is promised.
