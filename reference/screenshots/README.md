# Reference screenshots

No household screenshots were copied into this public repository. No current live capture was possible during bootstrap. The private source handoff describes earlier desktop/test-clone screenshots; those are historical evidence, not new physical TouchHub acceptance.

For future visual comparison, use an isolated demo dashboard with synthetic people, generic initials/icons, fictional places and no private URLs or keys. Capture portrait, landscape, grouped markers, expanded markers, member focus, category reset and kiosk exit. Review every pixel and remove metadata before deliberately adding an approved image. Record viewport, build, device and verification date next to each approved capture. The privacy hook blocks image binaries by default; add a narrowly reviewed allowance only for sanitized demo assets.
