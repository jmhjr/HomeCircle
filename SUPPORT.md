# Getting support

Start with the [setup guide](docs/RELEASE-1.0-USER-GUIDE.md),
[troubleshooting](docs/RELEASE-1.0-TROUBLESHOOTING.md) and
[maintenance and recovery](docs/RELEASE-1.0-MAINTENANCE.md).
HomeCircle 1.0 is still in preparation; use the exact version named in a release
and keep the published experimental beta's limits in mind.

For a non-sensitive bug or setup question, open a
[HomeCircle issue](https://github.com/jmhjr/HomeCircle/issues) with the version,
HAOS/Core versions, installation method, expected and actual behavior, and safe
steps using fictional data where possible. Read diagnostics locally and quote
only fixed status codes and aggregate counts needed to explain the problem.
No log, backup, account export or diagnostic-file upload is required.

Do not send credentials, verification codes, device passcodes, tokens, vault/key
files, raw provider replies, private identifiers, coordinates, addresses, location
screenshots or opaque photo URLs. Do not repeat sign-ins or passcode recovery to
make a support report. Use [private security reporting](SECURITY.md) for a
suspected vulnerability.

HomeCircle offers no hosted account relay, telemetry or support-upload service.
Direct Apple Find My and Life360 connections are optional and unofficial; those
providers can restrict access or return delayed reports. Standard HA trackers
remain usable without a direct HomeCircle provider account. HomeCircle is not
an emergency service and cannot guarantee a person's presence or safety.
See [privacy and support](docs/RELEASE-1.0-PRIVACY-SUPPORT.md) for external map,
portrait, city-lookup and provider requests.

The maintainer does not promise a response time or provider availability.
Provider names identify compatibility; no provider affiliation or endorsement
is claimed.
